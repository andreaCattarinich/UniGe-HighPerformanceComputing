\subsection{Algorithm Optimization}
The first instruction is not vectorizable under MSVC, resulting in suboptimal performance.\\

\noindent
Under Linux with G++, however, the \texttt{std::complex} operations appear to be better optimized:

\begin{lstlisting}
    z = pow(z, 2) + c;
\end{lstlisting}

\noindent
The \texttt{std::complex} implementation relies on operator overloading (\texttt{operator+} and \texttt{operator*}), which introduces additional overhead on the CPU. Furthermore, the \texttt{abs(z)} function computes a square root every iteration.\\

\noindent
To remove this dependency on complex numbers, the code was refactored to use only real numbers. By exploiting the relation:

\[
z^2 = (a, b)^2 = (a^2 - b^2, \; 2ab)
\]

\noindent
we implemented:

\[
z^2 = \big(\operatorname{Re}(z), \operatorname{Im}(z)\big)^2 
      = \big(\operatorname{Re}(z)^2 - \operatorname{Im}(z)^2, \; 2\,\operatorname{Re}(z)\operatorname{Im}(z)\big)
\]

\noindent
as follows:

\begin{lstlisting}
    double zRe = 0, zIm = 0;
    for (int i = 1; i <= ITERATIONS; i++)
    {
        double oldRe = zRe;
        double zRe2 = zRe*zRe; // Re(z)^2
        double zIm2 = zIm*zIm; // Im(z)^2

        zRe = (zRe2 - zIm2) + cRe;
        zIm = 2*oldRe*zIm + cIm;

        if(zRe2 + zIm2 >= 4)
        {
            image[pos] = i;
            break;
        }
    }
\end{lstlisting}

\noindent
As expected, this optimization significantly improves performance.
