This repository contains three HPC projects demonstrating parallel programming techniques using **OpenMP** and **CUDA**. Each project focuses on a different computational pattern and highlights how parallelism can improve performance on modern hardware.


## Discrete Fourier Transform (DFT) with OpenMP
[Download the full report (PDF)](/reports/discrete-fourier-transform-OpenMP/OpenMP-discrete-fourier-transform.pdf)

A parallel implementation of the Discrete Fourier Transform using **OpenMP**.
The project shows how data-parallel loops can be efficiently distributed across CPU cores.

![Report Preview](/reports/discrete-fourier-transform-OpenMP/assets/dft-openmp-preview.png)


## Heat Conduction Simulation with CUDA
[Download the full report (PDF)](/reports/heat-equation-CUDA/CUDA-heat-equation.pdf)

A 2D heat diffusion solver implemented on the GPU using **CUDA**.

![Report Preview](/reports/heat-equation-CUDA/assets/heat-cuda-preview.png)


## Mandelbrot Set with CUDA and OpenMP
[Download the full report (PDF)](/reports/mandelbrot-OpenMP-CUDA/mandelbort.pdf)

A high-resolution Mandelbrot fractal generator implemented using both **CUDA** and **OpenMP**.

![Report Preview](/reports/mandelbrot-OpenMP-CUDA/assets/mandelbrot-openmp-cuda-preview.png)
