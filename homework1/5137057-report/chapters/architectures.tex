\section{Architectures}
For this project I have used two workstation, my personal one and the workstation provided by the University.

\subsubsection*{HP Envy 17-ae103nl (Laptop)}
\begin{itemize}
    \item \textbf{CPU}: Intel Core i7-6500U @ 2.50 GHz
    \item \textbf{Architecture}: x86\_64
    \item \textbf{Core fisici}: 2
    \item \textbf{Thread logici}: 4 (Hyper-Threading)
\end{itemize}

\subsubsection*{University Workstation}
\begin{itemize}
    \item \textbf{CPU}: Intel Core i9-12900K (12th Gen)
    \item \textbf{Architecture}: x86\_64
    \item \textbf{Core(s) per socket}: 16
    \item \textbf{CPU(s)}: 24
    \item \textbf{Thread(s) per core}: 2
    \item \textbf{Socket(s)}: 1
    \item \textbf{CPU max MHz}: 4.02 GHz
\end{itemize}

\noindent
To use the Intel oneAPI tools on the University workstation, the environment was loaded with:
\begin{verbatim}
source /opt/intel/oneapi/setvars.sh
\end{verbatim}
